# mapstyles.aeroverra.com

Live basemap A/B preview for the travel maps. Same data, same routes, same code as
travel.aeroverra.com - the only difference is a basemap picker in the filter bar.

Background: CARTO started requiring an API key for `basemaps.cartocdn.com` in Sept 2026, so
every travel map had to move off it. This page exists to pick the replacement.

Pick a style from the dropdown; the choice is saved to localStorage. Tell Azula which one wins
and it gets baked into travel / travel2 / michael / sharon / adrianahlee.
